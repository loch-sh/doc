## loch hosting get

Show the settings, containers and last operation of a stack

```
loch hosting get <name> [flags]
```

### Options

```
      --compose   Print only the compose.yaml of the stack, as it is on disk
  -h, --help      help for get
  -v, --verbose   Show environment values, snippet contents and the compose output of the last operation
```
