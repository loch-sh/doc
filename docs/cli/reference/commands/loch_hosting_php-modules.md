## loch hosting php-modules

List the PHP modules of an image (may pull the image on first use)

```
loch hosting php-modules [flags]
```

### Options

```
  -h, --help              help for php-modules
      --php string        PHP version (default: the server default)
  -t, --template string   PHP template: php-nginx or php-apache (default "php-nginx")
```
