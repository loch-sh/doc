## loch hosting deploy

Redeploy a hosted stack as it is on disk

```
loch hosting deploy <name> [flags]
```

### Options

```
      --force     Deploy a compose file modified outside the panel as is
  -h, --help      help for deploy
      --no-wait   Return as soon as the operation is started
      --pull      Pull the latest image before deploying
```
